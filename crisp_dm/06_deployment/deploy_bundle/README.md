# Paquete de despliegue Streamlit

Este directorio contiene únicamente la aplicación y datos agregados anonimizados, incluidos los conteos por banda de confianza. No incluye CSV de comentarios, autores, IDs, URLs, archivos crudos ni modelos.

Instale `requirements.txt` y ejecute `streamlit run app.py`. Para desplegar, use este directorio como raíz del repositorio de la app.
