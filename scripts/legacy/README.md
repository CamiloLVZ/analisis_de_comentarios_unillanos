# Scripts heredados de recolección

Estos scripts se conservaron separados del análisis CRISP-DM para que el flujo actual sea fácil de seguir. Incluyen auditorías auxiliares, descarga de publicaciones/comentarios, generación de lotes y unificación.

No se ejecutan para reconstruir las salidas de este proyecto: la entrada canónica es `data/final/comments_unified.csv`. Se ajustaron las rutas relativas del proyecto raíz al moverlos. Sus dependencias de extracción/API pueden requerir instalaciones y credenciales que no están incluidas en los requisitos del dashboard; no se versionan credenciales ni se vuelve a contactar a las plataformas.
